# Nagarik citizen portal demo

A complete responsive React Router demonstration of a unified Nepal government services platform.

## Included flows

- Searchable catalogue of 65 public services across 11 categories
- Service detail pages and universal four-step applications
- Local document wallet with upload and verification states
- Central academic wallet for any recognized university, board, or technical institution
- QR-verifiable e-diplomas and issuer synchronization requests
- Official IRD links for tax services
- Application tracking and digital certificate downloads
- Linked government bills and simulated PIN payments
- Citizen inbox, privacy controls, profile security, helpdesk, terms, and privacy policy
- Browser-persisted demo state with responsive desktop and mobile navigation

All transactions are simulated in the browser. No submissions or payments reach a government system.

## Commands

```sh
npm run dev
npm run typecheck
npm run build
npm run preview
```
